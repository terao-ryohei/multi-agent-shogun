Translate a Minecraft mod's en_us.json to Japanese (ja_jp.json) using Python 2-phase pattern matching.

## Arguments

$ARGUMENTS = `<path-to-jar-or-en_us.json>` `[modid]`

- First argument: path to a .jar mod file or an en_us.json file
- Second argument (optional): modid override (auto-detected if omitted)

## Procedure

### Step 1: Parse Input and Extract en_us.json

**If the path is a .jar file:**
1. Find en_us.json: `unzip -l <jar> | grep en_us.json`
2. Extract the path (e.g., `assets/<modid>/lang/en_us.json`)
3. Extract the file: `unzip -p <jar> <en_us_path> > /tmp/mc_translate_en_us.json`
4. Detect modid from the jar internal path (the directory under `assets/`)

**If the path is a .json file:**
1. Copy or read the file directly: `cp <path> /tmp/mc_translate_en_us.json`
2. Detect modid from directory structure (e.g., `assets/<modid>/lang/en_us.json`)
3. If modid cannot be detected, require the second argument

**If modid override is provided, use that instead of auto-detection.**

### Step 2: Analyze the Input

Run a quick analysis to understand the scale:
```bash

import json
```

```python
def translate_value(value):
    """2-phase translation: multi-word first, then single-word with boundaries."""
    # Skip if already mostly non-ASCII (likely already translated or Japanese)
    ascii_chars = sum(1 for c in value if ord(c) < 128 and c.isalpha())
    if ascii_chars == 0:
        return value

    # Phase 1: Multi-word replacements (simple string replace, longest first)
    for en, ja in MULTI_WORD:
        if en in value:
            value = value.replace(en, ja)

    # Phase 2: Single-word replacements (regex word boundary)
    for en, ja in SINGLE_WORD:
        if en in value:
            value = re.sub(r'\b' + re.escape(en) + r'\b', ja, value)

    return value


def main():
    if len(sys.argv) < 3:
        print("Usage: python3 mc_translate.py <input.json> <output.json>")
        sys.exit(1)

    input_path = sys.argv[1]
    output_path = sys.argv[2]

    with open(input_path, encoding='utf-8') as f:
        data = json.load(f)

    result = {}
    translated_count = 0
    for key, value in data.items():
        original = value
        translated = translate_value(value)
        result[key] = translated
        if translated != original:
            translated_count += 1

    with open(output_path, 'w', encoding='utf-8') as f:
        json.dump(result, f, ensure_ascii=False, indent=4)

    # Report
    total = len(data)
    # Count remaining English fragments
    remaining_en = 0
    en_samples = []
    for key, value in result.items():
        ascii_words = re.findall(r'[A-Za-z]{2,}', value)
        # Filter out known exceptions (mod names, proper nouns in keys)
        real_en = [w for w in ascii_words if w not in ('OwO', 'TNT', 'II', 'III', 'IV', 'SFX')]
        if real_en:
            remaining_en += 1
            if len(en_samples) < 10:
                en_samples.append(f"  {key}: {value}")

    print(f"Total keys: {total}")
    print(f"Keys modified: {translated_count}")
    print(f"Keys with remaining English: {remaining_en}")
    if en_samples:
        print("Sample remaining English:")
        for s in en_samples:
            print(s)


if __name__ == '__main__':
    main()
```
